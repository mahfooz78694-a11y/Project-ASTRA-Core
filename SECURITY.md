# Security Policy

## Supported Versions

The following versions of Project ASTRA are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v2.0    | :white_check_mark: |
| < v2.0  | :x:                |

## Vulnerability Disclosure Protocol

We take the security of our Off-Chain AI Guardrails seriously. If you discover a vulnerability or potential weakness in the Float64 Nullspace projection engine, tensor bounds guarding, or DePIN proof generation pipeline, please report it privately.

1. **Do not disclose the vulnerability publicly** until a fix is released.
2. Please email a detailed report, including steps to reproduce the vulnerability, to the core maintainers.
3. We will acknowledge receipt within 48 hours and provide a timeline for the patch.

Any valid security vulnerabilities that impact runtime integrity or mathematical constraints will be credited in our subsequent release notes.
